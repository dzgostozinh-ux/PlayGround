## Como jogar

Uma campanha de sobrevivência em primeira pessoa, executada no navegador. Abra `index.html` por um servidor local (por exemplo, `./start.sh`) e selecione **Iniciar campanha**. Sobreviva às três ondas de cada setor, recolha suprimentos, use as moedas no arsenal entre setores e derrote o chefe final.

- **Desktop:** WASD para mover, mouse para mirar, clique para atirar, `R` para recarregar, `B` para abrir o arsenal e `1`/`2`/`3` para trocar de arma. Clique no jogo para capturar o mouse; `Esc` libera o cursor.
- **Celular/tablet:** joystick à esquerda, arraste no lado direito para mirar, **FOGO** para disparar, **R** para recarregar, **ARSENAL** para comprar e os botões `1`/`2`/`3` para trocar de arma.

O arsenal de demonstração dá moedas iniciais para testar compras; a campanha normal começa sem esse bônus. Requer conexão para carregar Three.js do unpkg.
